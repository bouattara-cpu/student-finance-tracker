# Student Finance Tracker

A responsive web application built with Vanilla JavaScript, HTML, and CSS to track personal student finances, validate transaction inputs with Regular Expressions (Regex), and offer data persistence and accessibility features.

- **Demo Video**: [Watch Demo Video](https://youtu.be/idMf6f3uWG4)

---

## ✨ Features
- **Dashboard & Stats**: Real-time summary of total transactions, total amount spent, and top spending categories.
- **Transaction Management**: Add, view, edit, and delete expense/income records.
- **Regex Input Validation**: Form inputs (date, description, amount) are validated using strict Regular Expressions.
- **Live Search**: Interactive live search powered by dynamic Regex that filters transactions and highlights matching query text in real-time.
- **Data Import / Export**: Persistent local storage (`localStorage`) with full support for JSON backup exports and imports.
- **Budget Cap**: Option to configure a custom monthly spending cap.
- **Accessibility (WCAG)**: Fully navigable via keyboard using standard `Tab` and `Enter` keys with clear focus indicators.
- **Responsive Design**: Mobile-friendly layout optimized for both desktop and mobile viewports.

---

## 🛠️ Tech Stack
- **HTML5**: Semantic markup
- **CSS3**: Responsive flexbox and custom styling
- **JavaScript (ES6+)**: Modular code structure (`app.js`, `ui.js`, `validators.js`, `storage.js`, `state.js`, `search.js`)
